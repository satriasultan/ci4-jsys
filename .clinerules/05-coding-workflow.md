
# DEVELOPMENT WORKFLOW

## BEFORE CODING

1. Understand the requested task.
2. Identify the relevant module.
3. Inspect only required files.
4. Understand existing implementation.
5. Identify dependencies.

## DURING CODING

1. Modify only necessary files.
2. Preserve existing architecture.
3. Avoid unrelated refactoring.
4. Avoid duplicate functions.
5. Keep changes minimal.
6. Never modify database objects.

## AFTER CODING

1. Check syntax of modified PHP files.
2. Check relevant JavaScript syntax.
3. Inspect changed code for errors.
4. Report modified files.
5. Report any remaining issues.

## IMPORTANT

Do not perform full project analysis unless
explicitly requested.

Do not run unnecessary commands.

Do not reinstall dependencies.

Do not execute composer update or npm update
unless explicitly requested.
